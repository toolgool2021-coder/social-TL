# NEXORA 3.3 — публикация Firebase

## Проверка перед публикацией

В репозитории GitHub Actions **Firebase integration** выполняет `npm test`, включая тесты Firestore Rules в эмуляторе. **Pages build and deployment** публикует статические файлы сайта, но **не** публикует Firestore Rules и Cloud Functions в Firebase. Успешный GitHub Actions не означает, что Firebase Console уже использует новые правила.

## Шаг 1. Опубликовать Firestore Rules

1. Открой https://console.firebase.google.com/project/toolchat-bfac8/firestore/rules
2. Скопируй **весь** файл https://raw.githubusercontent.com/toolgool2021-coder/social-TL/main/firestore.rules
3. Замени старые правила полностью, затем нажми **Publish / Опубликовать**.
4. Проверь в браузере под двумя тестовыми аккаунтами, что сообщения, блокировки, приватность и галереи работают.

Не смешивай старые и новые правила. Перед заменой сохрани резервную копию текущих правил.

## Шаг 2. Cloud Functions (отдельная операция)

Файл `functions/index.js` содержит серверные обработчики уведомлений. Изменения этого файла не активируются публикацией GitHub Pages или вставкой Firestore Rules. Для их активации требуется отдельный деплой Cloud Functions в проект `toolchat-bfac8` с учётной записью, имеющей права на развёртывание:

```sh
npx firebase-tools deploy --only functions --project toolchat-bfac8
```

Команда требует установленного Node.js, входа в Firebase CLI и соответствующих прав. Выполняй её из корня репозитория после установки зависимостей.

## Шаг 3. Контроль

- Создать пост с 1–4 HTTPS-изображениями; проверить старые посты.
- Заблокировать пользователя и проверить невозможность отправки нового сообщения.
- Включить «Никто» в приватности переписки; проверить отправку с другого аккаунта.
- Проверить уведомления, счётчики, отметку «Прочитать все».
- Проверить мобильную версию и выход/повторный вход.

## Известные ограничения

- Счётчики в списке диалогов показывают непрочитанные **уведомления**, а не точное число всех непрочитанных сообщений.
- Дополнительные изображения добавляются HTTPS-ссылками; загрузка нескольких локальных файлов за один раз не реализована.
- Публикация Firebase Rules и Cloud Functions должна быть выполнена отдельно, если нет настроенного CI с Firebase credentials.
